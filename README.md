# 📘 Dana ElectroMart – Full Stack E-Commerce System

## 🧾 Project Overview
Dana ElectroMart is a full-stack e-commerce web application built using Node.js, Express, SQLite, Redis, and Docker.  
It demonstrates a modern web system with product browsing, cart management, and order processing.

The system also includes DevOps concepts such as containerization and caching to improve performance and scalability.

---

# 🚀 Features

## 👤 User Features
- Login (simple local storage authentication)
- View products
- Add products to cart
- View total price
- Place orders

## 🛠 Backend Features
- REST API (Express.js)
- Product management API
- Order processing API
- SQLite database integration
- Redis caching for products

## 🐳 DevOps Features
- Docker containerization
- Docker Compose orchestration
- Redis caching layer
- Scalable architecture design
